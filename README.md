# Order Priority, demo

A working demo of Order Priority, a personal priority tracker for corporate
gifting orders. Every order in it is fictional. Anything you change stays in
your own browser, and "Reset the demo" puts it back.

Open it at https://camerz0n3.github.io/order-priority-demo/

`index.html` is built from the main project with `npm run publish-demo`.
Do not edit it by hand.
